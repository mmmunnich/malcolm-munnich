CCL Baseball Analytics Platform

An end-to-end analytics platform combining event data, pitch and batted-ball measurements, statistical modeling, and interactive decision-support tools for player and team evaluation.

PythonJavaScriptRE24Expected statsData pipelinesDashboard

What I built

The platform brings several analytical layers into one interface: player leaderboards, team and game views, win probability, batted-ball visualization, expected statistics, fielding evaluation, league percentiles, and supporting tools for scouting and decision support.

Data pipeline

Joins box-score and tracking-style event data into player, game, and team views.

Modeling

RE24, empirical linear weights, expected outcomes, fielding opportunity models, and league-relative metrics.

Visualization

Interactive leaderboards, spray charts, win-probability curves, percentiles, and game reports.

Decision support

Turns model outputs into views an analyst or coach can use to compare players and understand game context.

Modeling components

RE24 + linear weights

Run-expectancy states provide a common run-value framework for events.

Expected statistics

Contact-quality features are used to estimate expected hit outcomes and expected rate statistics.

Fielding evaluation

Models the probability of converting a defensive opportunity and compares observed outcomes with expectation.

League-relative metrics

Context-aware metrics allow players to be compared within the same league environment.

What this project demonstrates

  • Building a data pipeline rather than relying on a single analysis file.
  • Turning statistical models into usable interfaces.
  • Joining multiple data sources and handling entity-matching problems.
  • Communicating complex metrics through tables and visualizations.
  • Thinking critically about model coverage, assumptions, and limitations.
